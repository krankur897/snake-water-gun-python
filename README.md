# 🐍 Snake Water Gun Game

A simple **Snake, Water & Gun** game built with Python as part of my journey into programming and problem-solving.

## 🎮 How to Play

Choose one of the following options:

* `s` → Snake 🐍
* `w` → Water 💧
* `g` → Gun 🔫

The computer randomly selects an option, and the winner is determined according to the game rules.

## 🛠️ Concepts Used

* Python fundamentals
* Variables
* Dictionaries
* User input
* `if-else` statements
* `random` module
* `random.choice()`
* Basic problem-solving and game logic

## ▶️ How to Run

Make sure Python is installed on your system.

Run the following command:

```bash
python game.py
```
